\noindent\textbf{Status:} Active internal plan (pre-call freeze period)\\
\textbf{Objective:} Convert Agent Audit Kit into repeatable revenue while preserving Lane B non-claims discipline.

\section*{Strategy}
AAK is sold as a deterministic decision-lineage and evidence primitive for high-liability AI workflows.

\medskip
\noindent AAK is \textbf{not} sold as:
\begin{itemize}
  \item compliance certification
  \item legal guarantee
  \item governance authority engine
\end{itemize}

\section*{Critical Path Sequencing}
\subsection*{Phase 0 (Now through Giuseppe call)}
\textbf{Primary focus:}
\begin{itemize}
  \item MathLedger clean repo waves (A0--A4)
  \item Three-lane experiment pipeline (A5--A7)
  \item Preliminary results and call preparation
\end{itemize}

\textbf{AAK scope in this phase:}
\begin{itemize}
  \item maintain release quality only
  \item ship claim-language hygiene
  \item ship scoring-provenance contract scaffolding
  \item no broad outreach campaign yet
\end{itemize}

\subsection*{Phase 1 (Immediately after call, Days 1--30)}
\textbf{Primary outcome:} Close one lighthouse engagement.

\begin{itemize}
  \item Build 40-account ICP list (regional banks/credit unions first)
  \item Execute 5 high-quality targeted outreaches per week
  \item Run discovery calls and push fixed-scope pilot close
  \item Close 2 paid audits target (minimum 1 lighthouse)
\end{itemize}

\subsection*{Phase 2 (Days 31--90)}
\textbf{Primary outcome:} Convert one-off audits into recurring revenue.

\begin{itemize}
  \item Convert findings into remediation sprint offers
  \item Convert remediation into evidence assurance retainers
  \item Publish anonymized case evidence with measurable deltas
\end{itemize}

\section*{Offer Ladder}
\begin{itemize}
  \item Tier 1: AI Decision Exposure Audit (\$2{,}500)
  \item Tier 2: Expanded Audit + onsite readout (\$5{,}000)
  \item Tier 3: Remediation Sprint (\$7{,}500--\$15{,}000)
  \item Tier 4: Evidence Assurance Retainer (\$2{,}000--\$4{,}000/month or annual equivalent)
\end{itemize}

\section*{ICP and Buyer Roles}
\textbf{Priority ICP:}
\begin{itemize}
  \item regional banks and credit unions
  \item insurance operators
  \item healthcare billing processors
  \item legal operations teams using AI automation
\end{itemize}

\textbf{Buyer roles:}
\begin{itemize}
  \item CTO
  \item CISO
  \item Head of Risk/Compliance
  \item Internal Audit Lead
\end{itemize}

\section*{Default Sales Question}
\textit{If a wire, lending, or other AI-influenced decision is challenged next quarter, can you reconstruct the exact prompt chain, tool calls, and influence context with tamper-evident evidence?}

\section*{Architecture Requirements for Revenue Credibility}
\textbf{Must-have controls:}
\begin{itemize}
  \item deterministic replay and fail-closed verification
  \item deterministic narrative report output
  \item psych scoring provenance contract and versioned classifier metadata
  \item explicit synthetic vs live labeling in reports
\end{itemize}

\textbf{Do not add during this cycle:}
\begin{itemize}
  \item dashboards
  \item hosted SaaS workflows
  \item compliance-certification language
  \item broad feature expansion
\end{itemize}

\section*{KPI Targets}
\textbf{Phase 1 KPIs:}
\begin{itemize}
  \item 5 targeted outreaches per week
  \item 4 or more discovery calls per month
  \item 1--2 paid audits per month
\end{itemize}

\textbf{Phase 2 KPIs:}
\begin{itemize}
  \item 30\%+ audit-to-remediation conversion
  \item 20\%+ remediation-to-retainer conversion
  \item first referenceable lighthouse case
\end{itemize}

\section*{Commercial + Research Flywheel}
Each real engagement should produce:
\begin{itemize}
  \item paid revenue
  \item case-study evidence for sales
  \item anonymized empirical data for research
\end{itemize}

\section*{Risk Controls}
\begin{itemize}
  \item change messaging before changing architecture
  \item maintain non-claims discipline in all artifacts
  \item freeze scope during active pilot delivery
  \item require deterministic evidence before making outward claims
\end{itemize}

AAK is in freeze mode until after the Giuseppe collaboration call. New feature work is paused. Focus remains on MathLedger critical path and experiment scaffold readiness.
